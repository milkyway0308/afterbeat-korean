# Afterbeat 한글패치 v1.1.0

1. 게임을 종료합니다.
2. 이 `KoreanLocalization` 폴더를 `Afterbeat.exe` 옆의 `Mods` 폴더 안에 넣습니다.
3. Steam 라이브러리에서 Afterbeat를 실행합니다. 처음 설치하면 한국어로 전환됩니다.

Windows Steam 빌드 **25787377**(게임 표시 버전 **26.10.6**, Unity **2021.3.45f2**)에서 확인했습니다. 별도 모드 로더나 폰트는 필요하지 않습니다.

게임의 실행 파일·원본 DLL·세이브는 교체하지 않습니다. 다른 언어는 게임 설정의 Video / Language에서 선택할 수 있습니다.

모드를 끄려면 게임을 종료한 뒤 폴더 이름을 `KoreanLocalization.disabled`로 바꾸세요. 한국어 선택을 초기화하려면 게임을 종료하고 이 폴더의 `activated.txt`만 삭제하세요.

이번 버전은 2,439개 원문 항목을 재검토해 기존 번역 589개 항목을 수정했습니다. 인물의 말투와 대사 연결, 반복·말더듬·손상 표현을 다듬고 문서·메뉴의 인명과 용어를 맞췄습니다. 음악 재생 식별자는 원문을 유지합니다.

게임 내 번역 테이블·폰트·언어 전환 검사를 통과했습니다. 별도의 Ink 실행 대조에서 37개 스크립트의 화자·감정 태그, 선택지 목적지와 외부 명령 인수를 확인했습니다. 전체 스토리 분기를 직접 플레이한 검수는 하지 않았습니다. 이미지 속 글자와 일부 동적 UI에는 영어가 남을 수 있습니다.
